# 缺失结构与证据补全

先读取所选 JSON 中的结构和元素要求，再通过 `analyze-missing` 区分可安全补齐、可基于证据起草和需要真实材料三类。结合稿型判断结构，避免机械增加不适用的目录或章节。

通过 `complete` 补原生目录、既有标题编号、明确提供的图表题注序号和页码。目录采用真实标题，实际页码由已有 Word 布局刷新。新增节点继续应用相应 JSON 角色规则。

摘要、关键词、衔接和结论性文字只在用户明确启用实质完善后起草。每项附原稿块 ID、原文引句与修改记录。通过校验的原文抽取可以写入；其他生成草稿保留为待审核记录，由宿主核对事实和表达。

实验、数据、文献、作者、单位、基金和伦理信息必须来自真实材料。格式规则只决定已有内容的呈现，不提供研究事实。补全后检查原有对象、原文、新增内容依据和所用格式要求。
