# LaTeX 规则排版

保留原生工程的正文、子文件、宏、图片、公式和文献数据，不先转成 Word 或 Markdown 重建。

通过 `inspect` 确定工程结构，通过内置 JSON 或 `learn-style` 提取的参考规则确定格式。参考模板仅作为规则提取输入；应用阶段使用明确的字体、字号、间距、元素位置及页面几何数据，不复制或加载原模板类、样式、BibTeX 样式或源压缩包。

读取 `rules`、`page` 与 `extracted_format`，覆盖标题、作者、单位、摘要、关键词、各级标题、正文、数学、图表、题注、参考文献、页眉页脚、纸张、分栏和栏距。保留单位、角色、语言、稿型及条件；文档类名称、选项和宏包清单不能作为已提取的版式数据。

以受控操作生成 JSON 所确定的排版设置。使用原稿语义内容和文献条目，不借用参考模板正文。数学内容、定理、图表与引用关系保持原生结构，元素格式分别按明确规则处理。

调用已有 latexmk、XeLaTeX、pdfLaTeX 或 Tectonic，固定禁用 shell escape，忽略工程内的自动执行配置，并在临时副本中编译。预检拒绝外部路径、系统命令及无法安全处理的高风险输入。无需下载原模板源或建立额外环境。

根据真实日志与页面查看公式、图表、引用、字体、分栏、栏距和空白。局部修复受控参数后重新检查，交付可编辑工程及必要 PDF 和报告。

能力以当前引擎检查结果为准。自定义语义宏、作者单位的任意写法、双语角色及部分出版专用布局可能需要宿主映射或人工核对；LaTeX 暂不接受 `plan --roles` 覆盖。内置配置的 `partial` 不代表所有条件已执行，来源与 Schema 检查也不能证明最终页面满足要求。检查 `requirements` 中每个 `UNKNOWN`、`UNVERIFIED` 及编译日志，再检查所有页面。固定行距可能让高对象重叠，最小行距允许高对象扩展，不能互换两者来消除视觉失败。
