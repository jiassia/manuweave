# Word 规则排版

通过 `scripts/manuweave.py` 调用本地工具，用户无需掌握命令。原稿与参考文档始终保留，成果写入新路径。

有参考 Word 时，`learn-style` 提取实际生效格式，考虑继承、直接覆盖、中英文字体及多个同角色实例。提取标题、作者、单位、摘要、关键词、各级标题、正文、公式、图表、题注、参考文献、页眉页脚和纸张分栏规则，保存来源位置及条件。参考内容不进入目标稿件。

使用内置配置时，通过 `presets list/show/catalog` 读取 JSON。先核对 `rules`、`page` 与 `extracted_format`，再将真实块 ID 映射到对应角色。双语标题、作者、单位、摘要、关键词和图表题注分别匹配；段内字体变化和首段等例外保留条件。

执行字体字号、字形、对齐、缩进、段距、固定或最小行距等明确规则。页面规则包含纸张、边距、页眉页脚距离、分栏和栏距；有前置单栏与正文双栏要求时，按标明的正文起点设置分节。数学、表格、图片和题注采用各自规则，不将正文固定行距机械套在纯图段上。

引擎在副本中精确修改 OOXML，保留 OMML、原始媒体、关系、合并单元格、书签、字段、脚注和注释部件。禁止复制原模板对象或重建全文。角色歧义通过 `inspect` 的真实位置和 `plan --roles` 解决。

执行后比较原文和对象清单，通过现有 Word 或 LibreOffice 生成页面。查看公式、题注、表格、图片、标题换页、页眉页脚和实际字体，局部修复后复查。两篇稿件不必拥有相同页数。
